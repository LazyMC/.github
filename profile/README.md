###

<h2 align="left">Unser Ziel</h2>

###

<p align="left">
LazyMC v2 soll kein gewöhnlicher CityBuild-Server werden. Unser Fokus liegt auf einzigartigen Spielmechaniken, einer langfristig wartbaren Architektur und hochwertigen, selbst entwickelten Systemen. Qualität steht dabei immer vor Geschwindigkeit.
